# TRL-702: Phase 3 registry entry: GLX-9081 versus docetaxel in second-line KRAS G12C-mutant NSCLC (completed)

- **Source type:** trial_registry
- **Source ID:** clinicaltrials_gov
- **Publication date:** 2026-03-18
- **Confidence weight:** 0.95

Registry ID HEL-9081-301. Status: Completed. Randomized, open-label phase 3 study (n=345) comparing GLX-9081 to docetaxel in second-line KRAS G12C-mutant NSCLC. Primary outcome (PFS) met: hazard ratio 0.62 favoring GLX-9081 (95% CI 0.49-0.79). Overall survival is a key secondary endpoint; results are described as not yet mature, with follow-up ongoing at the time of this registry update.
