# INT-402: NovaCure Internal Toxicology Memo TOX-2024-031: Early NCX-7401 in vitro cardiac safety screen

- source_id: `novacure_internal_docs`
- source_type: `internal_report`
- date: 2024-11-01

Internal memo, NovaCure Preclinical Safety group. Early in vitro cardiac safety screen of NCX-7401 found no significant hERG channel inhibition at the concentrations tested at the time. Note: this screen used a narrower concentration range than the later published class-wide screen (see LIT-103, 2026) and should not be treated as the current safety position on cardiac risk without cross-checking more recent data.
