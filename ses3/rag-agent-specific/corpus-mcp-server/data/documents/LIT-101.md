# LIT-101: NX-14 receptor expression correlates with fibrotic tissue remodeling in murine models

- source_id: `pubmed_central`
- source_type: `literature`
- date: 2025-03-10

Journal of Fibrotic Disease Research, Vol. 41. In bleomycin-induced lung fibrosis models, NX-14 receptor expression increased 3.2-fold in fibrotic tissue relative to healthy controls (p<0.01, n=24). Receptor density correlated with collagen deposition score (r=0.71). Authors conclude NX-14 is a plausible druggable target for anti-fibrotic therapy, pending confirmation of a causal (not merely correlative) role.
